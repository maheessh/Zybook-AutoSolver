# Zybook-AutoSolver

Automates Zybooks participation activities from your browser console.

## Prerequisites
- A Zybooks account you can log into.
- Google Chrome, Edge, or Firefox.
- Browser Developer Tools access (Console tab).

## Run in Browser Console (after login)
1. Sign in to Zybooks and open the section/activity page you want to complete.
2. Open Developer Tools:
   - **Windows/Linux**: `F12` or `Ctrl+Shift+I`
   - **macOS**: `Cmd+Option+I`
3. Open the **Console** tab.
4. Paste the Zybook-AutoSolver JavaScript snippet into the console.
5. Press **Enter** to run it.
6. Keep the tab open until the automation completes.

## Tips
- If nothing happens, refresh the page and run the script again.
- Run the script only on Zybooks activity pages (not the Zybooks home/dashboard page).
- If your browser blocks paste in console, type `allow pasting` and press Enter, then paste again.
